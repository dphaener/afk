What the five decisions mean
Run
Usage is within the limits, so afk runs as normal.
Launch nothing new
A window is past the limit for starting new work (75% for the session, 85% for the week). Nothing new starts, and a running session carries on.
Pause
A window is at or past 90%. A running session is paused until the window resets.
Hold
The reading is missing or more than 30 minutes old. Nothing new starts and a running session is left alone.
Refuse
Extra usage is switched on for the account. afk will not run until you turn it off.

Those limits are the defaults. The [governor] table in config.toml can change them.
